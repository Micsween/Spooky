
##Spooky

Spooky is a scary point-and-click game made with GameMaker. It's a summer project I'm working on to learn GML. It's also an opportunity for me to practice using sequences and state machines.

Premise: With the promise of hungry customers, you decide to park your food truck outside a new excavation site. But this excavation site is hiding more than you realized.
